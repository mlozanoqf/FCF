# Historical FCF calendars

This folder preserves the previous FCF course calendars that existed before
the Fall 2026 Quarto syllabus was rebuilt from the shared syllabus template.

The most recent historical calendar is `Class schedule pr26.rmd`, used in
Spring 2026. The accompanying `9mybibfile-spring-2026.bib` file preserves the
bibliography available with that version.

The files in this folder are historical references and are not part of the
active Quarto book.
